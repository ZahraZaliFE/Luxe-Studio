# 💄 Luxe Studio — Modern Beauty & Wellness Landing Page

Luxe Studio is a **single‑page website** themed around luxury beauty, hair styling, skincare, and wellness services.  
The project focuses on an elegant layout, soft beige tones, and a calm, modern user experience.

---

## 🔗 Online Demo

View the live demo here:  
https://zahrazalife.github.io/LuxeStudio/

---

## 📝 Description

This project includes a **symbolic header** with navigation items such as *Home, Services, Gallery, About,* and *Contact*.  
Below the header, the page displays **several service cards** that introduce the main beauty services offered at Luxe Studio, including hair styling, facial treatments, nail design, and massage.

The website also features a **testimonial section**, showcasing a pinned review from a regular client of the studio.  
At the bottom of the page, a simple **footer** provides contact information and business details.

This project was built using **Bootstrap**, but kept intentionally simple —  
Bootstrap didn’t fully match the flexibility and vibe I enjoyed in Tailwind,  
so I created a clean and minimal layout without complex components.

---

## 🛠️ Technologies Used

- **HTML5**  
- **CSS (Bootstrap 5)**  
- **JavaScript** (used for the mobile hamburger menu)  
- **Responsive Design**
